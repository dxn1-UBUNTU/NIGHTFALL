# TUI

The TUI is intentionally dependency-free: Bun/Node standard terminal APIs plus ANSI escape sequences. This keeps startup fast and makes the interface portable. The renderer uses a sidebar, status strip, pane headers, tables, progress meters and modal editors.

Primary panes:

- Dashboard
- Surface Map
- Hosts
- Auth
- Findings
- Probes
- Queue
- Settings
- History
- Logs
- Help
